## Reporting a vulnerability

Please report suspected vulnerabilities **privately** — do not open a public issue.

- Email: **security@example.com** *(placeholder — replace before public release)*
- Preferred: use GitHub's **"Report a vulnerability"** (Security Advisories) once enabled for the
  repository.

Include:

- affected version or commit
- reproduction steps
- expected vs observed behavior
- potential impact

## Supported versions

This project is pre-1.0. During the `0.x` series, **only the latest released `0.x` version receives
security fixes.** Older `0.x` versions are not maintained; please upgrade to the latest release.

| Version | Supported |
|---|---|
| latest `0.x` | ✅ |
| older `0.x` | ❌ |

This policy will be revisited at the first stable (`1.0`) release.

## Response goals

- Acknowledge the report within 5 business days.
- Triage severity and scope.
- Ship a fix or mitigation and publish release notes when available.
